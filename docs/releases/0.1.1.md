A fix for the Indexing panel in Settings, and less app data in your index.

**Install:** download `WinFynd-Setup-0.1.1.exe` below and run it over 0.1.0. Your index, folders, shortcuts and models are kept. The installer isn't code-signed yet, so Windows SmartScreen warns the first time: click **More info**, then **Run anyway**.

## Fixed

- The Indexing panel in Settings showed only the first file's name. Files stored without meaning search (when Ollama isn't running) appeared as empty circles with no name. Every row now shows its file.
- Whole-PC indexing now also skips developer test data (`testdata`, `fixtures`, `__snapshots__`, `cassettes`), Go's module cache (`go\pkg\mod`), Anaconda, Miniconda, Miniforge and Scoop folders, and Python installs like `C:\Python312`. These hold thousands of machine-made files nobody searches for, and they slowed down the first index. Files already indexed from them are dropped when WinFynd starts.

`SHA256SUMS.txt` holds the installer's checksum. More at https://winfynd.vercel.app.
