Search by meaning now runs inside WinFynd, so you no longer need Ollama for it. This release also fixes the Indexing panel and keeps app data out of your index.

**Install:** download `WinFynd-Setup-0.1.1.exe` below and run it over 0.1.0. Your index, folders, shortcuts and models are kept. The installer isn't code-signed yet, so Windows SmartScreen warns the first time: click **More info**, then **Run anyway**.

## New

- **No Ollama needed for search.** WinFynd runs EmbeddingGemma 2 itself. On the first start after updating, it downloads the model from Hugging Face once (865 MB with photos, 310 MB for text only), then reads again any files that were stored without search by meaning. Ollama is now only needed for Ask, and the Models page can still switch search back to Ollama.
- **Lighter in the background.** The model loads only while there are files to read or a search to run, and unloads after 5 idle minutes. WinFynd starts with Windows (Settings > Privacy > Start with Windows), and closing Settings frees its memory, so only the search box and the indexer keep running.

## Fixed

- The Indexing panel in Settings showed only the first file's name. Files stored without search by meaning appeared as empty circles with no name. Every row now shows its file.
- Whole-PC indexing now also skips developer test data (`testdata`, `fixtures`, `__snapshots__`, `cassettes`), Go's module cache (`go\pkg\mod`), Anaconda, Miniconda, Miniforge and Scoop folders, and Python installs like `C:\Python312`. These hold thousands of machine-made files nobody searches for, and they slowed down the first index. Files already indexed from them are dropped when WinFynd starts.

`SHA256SUMS.txt` holds the installer's checksum. More at https://winfynd.vercel.app.
