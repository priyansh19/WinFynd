Shortcuts

Every key, and how to change it.

Four shortcuts work from any app, and you can change each one. Inside the search window, more keys open a file, show it in its folder or copy its path.

From any app

  • Alt+Space

    Open search

    Type what you remember, like “lease renewal” or “dog on the beach”. Press the keys again to put it away.

  • Alt+Shift+Space

    Talk to search

    Hold the keys, say what you’re looking for, then let go. Prefer to press once to start and again to stop? Switch it in Settings.

  • Ctrl+Alt+Space

    Ask a question

    Opens search in Ask mode. Ask “When does my lease renew?” and get a short answer with numbered sources. Needs Ollama and a chat model.

  • Win+Shift+F

    Search selected text

    Select words in any app, press the keys, and WinFynd searches for them.

In the search window

These work while the search window is open. The bar along its bottom shows the main ones for the selected result.

Enter
Open the file in its usual app. In Ask, it sends your question.
Ctrl+Enter
Show the file in its folder. Shift + Enter and Ctrl + Shift + E do the same.
Ctrl+Shift+C
Copy the file’s full path, ready to paste.
Ctrl+K
List what you can do with the file: open it, show it in its folder or copy its path. Shift + F10 and the Menu key open the same list.
↑Up arrow↓Down arrow
Move through the results. Page Up and Page Down jump five at a time.
?
Type it first to ask a question instead of searching, as in “? when does my lease renew”.
Backspace
In an empty Ask box, go back to searching.
Esc
Clear what you typed, then leave Ask, then close the window. Clicking anywhere else closes it too.

Change a shortcut

  1. Right-click the WinFynd icon in the notification area, next to the clock, and choose Settings.
  2. Open Shortcuts & voice and click Change next to the shortcut.
  3. Press the new keys. Esc cancels.

If another app already uses those keys, WinFynd tells you and keeps the old shortcut. Windows uses Alt + Space for a window’s menu; WinFynd takes it over while it runs.

Questions

What it reads, what it needs, where it keeps things.

Each answer is about version 0.1.0. Open one for the details.

Does it need the internet?

No. It goes online only when you download a model, and to check for updates.

Reading your files, searching them and answering questions all happen on your PC, so WinFynd works offline once its models are downloaded. It connects to the internet only:

  • when you click Download for a model. Search and Ask models come through Ollama from ollama.com; Whisper, for speech, comes from huggingface.co.
  • once a day, to check GitHub for a new version. Turn it off in Settings › Privacy.
  • during install, if Windows is missing the WebView2 runtime that WinFynd’s windows need.

Nothing about your files is sent. There is no account, no analytics and no cloud index. Every connection, on the Privacy page

Does it work without Ollama?

Yes, by exact words and file names. Ollama adds meaning, photos and Ask.

Without Ollama, WinFynd still finds files by the exact words in them and by their names, and Whisper still turns speech in recordings into words you can search. The result count at the bottom of the search window then ends in “exact words only”.

Ollama is free, from ollama.com. With it and the EmbeddingGemma 2 search model, you also get:

  • search by meaning, so “receipt for the blue sofa” finds an order confirmation that never says “receipt”
  • photos found by what is in them
  • moments in videos, found by what is on screen (with FFmpeg)
  • Ask: answers from your files, with numbered sources

Install it later and WinFynd catches up by itself: its next full check adds the files it already read to search by meaning. That check runs right after you download a model, and every 20 minutes.

Which files can it read?

Documents, slides, spreadsheets, code, photos, recordings and videos.
Documents
PDF, Word (.docx), OpenDocument text, HTML, Markdown and plain text
Slides
PowerPoint (.pptx)
Spreadsheets
Excel (.xlsx, .xlsm, .xls), OpenDocument (.ods), CSV and TSV
Code
35 code and config formats, from .py and .ts to .json and .yaml
Photos
JPG, PNG, WebP, GIF and BMP
Recordings
MP3, WAV, M4A, FLAC, OGG, AAC, WMA and Opus
Videos
MP4, MKV, MOV, AVI, WebM, WMV and M4V

Every other file is found by its name, folder, kind and year. Not read inside in 0.1.0: old .doc and .ppt files, HEIC, TIFF and RAW photos, and scanned PDFs with no text in them. Less common audio, like WMA and Opus, needs FFmpeg. How each kind is read

Why doesn’t it find text in my screenshots?

Version 0.1.0 doesn’t read text inside images.

Screenshots, photos of documents and scanned PDFs are not read for their words; there is no text recognition (OCR) in 0.1.0. With Ollama, images are matched by what they look like, so describe the picture rather than the words in it.

Kind and date still narrow it down. “screenshots last week” lists the pictures from the last two weeks, newest first, with “Photos” and “Last 2 weeks” as filters you can remove.

How much disk space does it use?

On the example PC: 4.1 GB of models and a 2.3 GB index.

Most of it is models, and you choose which ones you download:

  • Search model, EmbeddingGemma 2: 1.3 GB for Most accurate, 0.7 GB for Balanced, or 0.3 GB for Smallest, which reads text only.
  • Speech, Whisper: 466 MB for Small, the one setup offers. Base is 148 MB, Large v3 Turbo 574 MB.
  • Ask model, any chat model in Ollama: llama3.2 3B, for example, is 2.0 GB.
  • The index, which grows with your files.

The example PC used across this site has 51,204 files. Its index is 2.3 GB and its models take 4.1 GB.

Which folders does it search, and can I change them?

Every drive on your PC. Switch that off and pick folders instead.

By default WinFynd reads every drive on your PC: all of C: and any other drive, like D:. The switch is called Allow full OS context, in setup and in Settings › Folders.

Switch it off to choose folders instead. Documents, Pictures, Desktop and Downloads start ticked, and you can add any folder. Remove one and its files leave the index.

Reading the whole PC means the index holds text from files anywhere on it. All of it stays on this PC.

  • New, changed, moved and deleted files are picked up within a couple of seconds, and a full check every 20 minutes catches anything missed.
  • Always skipped: Windows and program folders like Windows, Program Files and AppData, the Recycle Bin, hidden folders like .git, and build folders like node_modules.
  • OneDrive files that live only in the cloud are found by name until you download them. WinFynd never downloads them itself.

Where is my data?

On your PC, in your Windows user folder.
%APPDATA%\app.winfynd.desktop
The index (index.sqlite3), the Whisper models and your settings.
%LOCALAPPDATA%\app.winfynd.desktop
The log file.
%LOCALAPPDATA%\WinFynd
The app itself.

Paste a path into the File Explorer address bar to open it. The index holds copies of the text WinFynd read from your files, plus their vectors. It isn’t encrypted; it sits in your user folder like other apps’ data. Search and Ask models are kept by Ollama, in its own folder.

Does it use my GPU?

It doesn’t need one.

Whisper turns speech into text on the processor, using all its cores but one, up to eight, so the PC stays responsive. Search by meaning and Ask run inside Ollama, which decides whether to use your graphics card.

The Most accurate search model works best on a PC with 16 GB of memory. Balanced and Smallest are smaller models, 0.7 GB and 0.3 GB.

Is it free?

Yes. No account, and its source is on GitHub.

WinFynd costs nothing and needs no account or sign-up. Its source code is on GitHub. Ollama is free too, and so is downloading the models.

How do I uninstall it?

From Windows Settings, like any app. Your files are never touched.

Open Windows Settings › Apps (Installed apps on Windows 11, Apps & features on Windows 10), find WinFynd and choose Uninstall.

  • Your own files are never touched.
  • Your index and settings stay unless you tick “Also delete my search index and settings”. Keep them and a reinstall picks up where you left off.
  • Models you downloaded with Ollama stay in Ollama. To get the space back, remove them there, for example with ollama rm embeddinggemma-2.

Troubleshooting

Six problems and their fixes.

Each one starts with what you see. Follow the steps in order.

Alt + Space does nothing

Either WinFynd isn’t running, or another app owns those keys. PowerToys Run, for example, uses Alt + Space too.

  1. Look for the WinFynd icon in the notification area, next to the clock. No icon? Start WinFynd from the Start menu.
  2. Open Settings › Shortcuts & voice. A shortcut another app owns says “Another app is using this shortcut. Pick a different one.”
  3. Click Change and press keys no other app uses, or change the shortcut in the other app.

Results only match names or exact words

Search by meaning needs Ollama running and the search model downloaded. Until then the search window says “exact words only” next to the result count.

  1. Open Settings › Models.
  2. If it says “Ollama isn’t running”, start Ollama from the Start menu, then click Check again. Not installed yet? It’s free from ollama.com.
  3. If EmbeddingGemma 2 says “Not downloaded”, click Download.

You don’t need to start over. The next full check, right after the download and then every 20 minutes, adds the files WinFynd already read to search by meaning. Finding photos by what’s in them also needs Most accurate or Balanced; Smallest reads text only.

Videos aren’t found by what’s on screen

Reading frames from videos needs FFmpeg, which WinFynd doesn’t include. Without it, videos are still found by name and, once Whisper is downloaded, MP4 and MKV videos by what’s said in them.

  1. Install FFmpeg. Open Terminal and run: winget install Gyan.FFmpeg
  2. In Settings › Models, click Check again next to “Search what’s shown in videos” and turn it on.
  3. Leave it to read. It takes up to 48 frames from each video, after your other files.

Frames are matched like photos, so this needs a search model that reads photos: Most accurate or Balanced. FFmpeg also lets WinFynd hear less common audio formats, like WMA and Opus.

Windows says “Windows protected your PC”

WinFynd 0.1.0 isn’t code-signed yet, so Microsoft Defender SmartScreen warns the first time you run the installer.

  1. Check that the installer came from github.com/priyansh19/WinFynd/releases.
  2. Click More info, then Run anyway.

It installs for your Windows account only, so there is no admin prompt after that.

The first read is taking a long time

The first time, WinFynd reads every file it searches: every drive by default, or the folders you picked. On the example PC, 51,204 files on C: and D: took 47 minutes. Recordings and videos go last, because writing down what’s said is the slow part.

  1. Keep going. Search works from the start and fills in as it reads.
  2. Close the window if you like. WinFynd carries on from the notification area; point at its icon to see “WinFynd · indexing 12,840 of 51,204 files”.
  3. Wait for the “WinFynd is ready” notification. After that, only new and changed files are read, within seconds.

A file that takes longer than 90 seconds to read is found by its name only, so one huge file can’t hold up the rest.

Where is the log file?

WinFynd writes what it does to a log file. It’s the first thing to attach when you report a problem.

%LOCALAPPDATA%\app.winfynd.desktop\logs\winfynd.log

Paste the path into the File Explorer address bar, or into Run (Win + R). Past 2 MB, older lines move to winfynd.old.log next to it. The log names files that were slow or failed to read, so look it over before you share it.

Report a problem

Still stuck? Open an issue on GitHub.

Include these four things, so the problem can be reproduced without a round of questions.

  1. 1
    Your WinFynd versionIn Settings › About. It’s in the installer’s name too, like WinFynd-Setup-0.1.0.exe.
  2. 2
    Your Windows versionPress Win + R, type winver and press Enter.
  3. 3
    What happenedWhat you did, what you expected and what you got. For a search, the words you typed.
  4. 4
    The log file%LOCALAPPDATA%\app.winfynd.desktop\logs\winfynd.log
