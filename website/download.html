What’s in 0.1.0

What you need

Only Windows is required.

Ollama and FFmpeg are free and optional. Ollama adds search by meaning, photos and Ask; with FFmpeg as well, WinFynd also searches video frames. Add either one before setup or any time later.

  • Windows 10 or 11, 64-bit

    Required

    An x64 PC; there is no build for Arm-based PCs yet. On Windows 11 its windows get the Mica backdrop, on Windows 10 a solid one.

  • Microsoft WebView2

    Automatic

    Draws WinFynd’s windows. It’s built into Windows 11. If a Windows 10 PC doesn’t have it, the installer downloads it from Microsoft first, so that one step needs an internet connection.

  • Ollama

    Optional

    Free, from ollama.com. It runs the search and Ask models on this PC, which gives you search by meaning, photos by what’s in them, video frames and Ask. Without it, WinFynd finds files by their exact words and names, and still transcribes speech.

    Get Ollama for Windows

  • FFmpeg

    Optional

    Lets WinFynd look at frames in your videos, and read less common audio like WMA and Opus. Install it with winget install Gyan.FFmpeg and WinFynd picks it up within 20 minutes, or straight away when you click Check again in Settings > Models.

Install

Three steps to your first search.

The whole app is inside the one file, so installing needs no internet connection unless your PC is missing WebView2.

  1. 1

    Run the installer

    Open WinFynd-Setup-0.1.0.exe. It installs to %LOCALAPPDATA%\WinFynd. Leave “Start WinFynd when I sign in” on, so Alt + Space always works.

    If Windows warns you first
  2. 2

    Let it copy

    It copies WinFynd to your user folder and adds it to Start and Apps. Cancel is off while it copies, so you can’t stop it halfway. Leave “Open WinFynd now” ticked and click Finish.

  3. 3

    Set it up

    WinFynd opens and asks three things: what to search, which search model and which shortcuts. That takes about two minutes. Then it reads your files in the background, and search works while it does.

    • Every drive on this PC by default, and the index stays on it. Switch off Allow full OS context to pick folders instead.
    • No Ollama yet? Skip the model and add it later.
    • Close the window whenever you like. Windows tells you when it’s ready.

SmartScreen

If Windows says it protected your PC.

WinFynd 0.1.0 isn’t code-signed yet, so Microsoft Defender SmartScreen doesn’t recognise its publisher and stops the installer the first time. The blue box means Windows doesn’t know the app yet, not that it found a problem.

  1. 1

    Click More info

    It’s the link under the message.

  2. 2

    Check the name, then click Run anyway

    The app should read WinFynd-Setup-0.1.0.exe. The publisher shows as unknown until the installer is signed.

Only do this for an installer you downloaded from the WinFynd releases page on GitHub.

Update and uninstall

Updates keep your index. Uninstalling never touches your files.

Update by running the new installer

Download the newer setup from the same page and run it. It updates WinFynd in place, keeps your index, folders, shortcuts and models, and keeps your sign-in choice. If WinFynd is running, setup closes it and starts it again in the tray.

WinFynd checks GitHub for a new version once a day, and you can turn that off.

Uninstall from Windows Settings > Apps

Find WinFynd in the list and choose Uninstall. Your own files are never touched. Your index and settings stay in AppData, so a reinstall picks up where you left off, unless you tick “Also delete my search index and settings”. Models you downloaded with Ollama stay in Ollama.
