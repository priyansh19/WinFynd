Connections

Every connection WinFynd can make.

There are six. WinFynd reads and searches with one of them, Ollama, which runs on this PC. The other five reach the internet only when you click Download or Get Ollama, when the installer needs WebView2, or once a day to check for updates.

Stored on this PC

What it keeps, and where.

Everything WinFynd writes lives in your Windows profile. The full paths below are from the example PC, where the user is called gupta.

It reads every drive, unless you choose folders.

By default WinFynd searches the whole PC: all of C: and every other drive. So the index can hold text from any file on the PC, and all of it stays on the PC. It skips system and app folders like Windows, Program Files and AppData.

To keep it to certain folders

Switch off Allow full OS context in setup or in Settings > Folders, then pick the folders. Documents, Pictures, Desktop and Downloads are ticked to start.

%APPDATA%\app.winfynd.desktopC:\Users\gupta\AppData\Roaming\app.winfynd.desktop
  • index.sqlite3with index.sqlite3-wal and -shm

    The search index: each file’s path and name, the text read from it in passages, and their vectors.

    2.3 GB
  • speech\ggml-small.bin

    Whisper Small, the speech model, once you download it.

    466 MB
  • engine.json

    Settings: what to search, the models you chose and your options.

  • hotkeys.json

    Your shortcuts and voice settings.

  • onboarding.json

    How far setup got.

%LOCALAPPDATA%\app.winfynd.desktopC:\Users\gupta\AppData\Local\app.winfynd.desktop
  • logs\winfynd.log

    The log: times, events and errors, including the paths of files that were slow or failed to read. Past 2 MB it moves to winfynd.old.log.

  • WebView2 cache

    What Microsoft’s WebView2 keeps for WinFynd’s own windows.

Elsewhere

  • %LOCALAPPDATA%\WinFynd

    The program itself. No data of yours.

  • HKCU\Software\Microsoft\Windows\CurrentVersion\Run

    A registry value named WinFynd that starts it in the tray when you sign in. It is only there if you left “Start WinFynd when I sign in” ticked while installing.

  • %TEMP%\winfynd-frames-*

    Still frames from a video while it is read. Deleted when that video is done.

  • Ollama’s own model folder

    Search and Ask models, like EmbeddingGemma 2 (1.3 GB). Ollama keeps these, not WinFynd.

The index holds copies of your text.

To search inside files, WinFynd keeps the text it read from them in passages, the words spoken in recordings and videos, and vectors for search by meaning. Photos and video frames are kept as vectors only, never as pictures. On the example PC, with 51,204 files on drives C: and D:, the index is 2.3 GB.

It is not encrypted.

It sits in your Windows profile and is protected like everything else there: by your Windows sign-in, and by BitLocker or Device Encryption if your drive uses it. Anyone who can open files in your profile can open the index.

A roaming profile can copy it.

%APPDATA% is the Roaming part of your profile. If your organisation uses roaming profiles, Windows may copy it to their server when you sign out, index included.

Never

What WinFynd never does.

Once your models are downloaded, WinFynd works with the internet off. Disconnect and try a search.

  • No account

    Nothing to sign up for or sign in to. WinFynd has no idea who you are.

  • No analytics or telemetry

    No usage statistics and no crash reports. There is no setting for it, because there is nothing to turn off.

  • No cloud index

    The index is a file on this PC. There is no WinFynd server to upload it to.

  • Voice is transcribed here

    Whisper runs inside WinFynd, on your PC’s processor. Speech in recordings, videos and voice searches becomes text without a sound leaving the PC.

  • Answers are written here

    Ask hands your question and the passages it found to a chat model in Ollama, like llama3.2 3B, on 127.0.0.1. The answer is written on this PC.

  • Searches stay here

    What you type goes to Ollama on this PC to be matched by meaning, and nowhere else.

Uninstall

Remove it, and everything it kept.

Uninstall WinFynd like any other app. Its uninstall window asks one question.

  1. 1

    Open Windows Settings > Apps

    Find WinFynd in the list and choose Uninstall. WinFynd’s uninstall window opens.

  2. 2

    Tick “Also delete my search index and settings”

    It is off by default, so a reinstall picks up where you left off. Ticked, it deletes both app.winfynd.desktop folders: the index, your settings, Whisper models and the log.

  3. 3

    Remove Ollama’s models, if you want

    Search and Ask models stay in Ollama, for other apps that use them. To remove one, run ollama rm embeddinggemma-2 in a terminal.

Ticked or not, your own files are never touched.

Left unticked

Removes the program. Your index and settings stay in AppData, ready if you install again.

Ticked

Also deletes both data folders:

  • %APPDATA%\app.winfynd.desktop
  • %LOCALAPPDATA%\app.winfynd.desktop

This website

This website doesn’t track you either.

It is plain HTML, CSS and a little JavaScript, and every file comes from this site.

  • No cookies

    None are set, so there is nothing to accept.

  • No analytics

    No counters, pixels or tracking scripts, the host’s included.

  • Nothing from anyone else

    No web fonts, CDNs or outside images. The pictures of WinFynd on these pages are drawn with HTML and CSS, not loaded as images.

  • Hosted on Vercel

    Like any web host, Vercel sees each request, including your IP address. Links to GitHub take you to github.com.

Every page arrives with this header, and your browser blocks anything it doesn’t allow, so nothing can load from another site:

Content-Security-Policy: default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; script-src 'self' 'unsafe-inline'; frame-ancestors 'none'; base-uri 'self'; form-action 'none'

Source on GitHub

Check it yourself.

WinFynd is free, and its source is on GitHub. You don’t have to take this page’s word for any of it.

  • Read the code

    ollama.rs refuses any Ollama address that isn’t this PC. speech.rs downloads Whisper from huggingface.co. Both are in this folder:

    Folder: src-tauri/src/engine

    Open the folder on GitHub

  • Watch it connect

    Open Resource Monitor, go to Network and search for something in WinFynd. Under TCP Connections, WinFynd connects to 127.0.0.1, port 11434: Ollama, on this PC.

    Win + R, then type resmon

  • Open the index

    Quit WinFynd from the tray, then open the index in any SQLite viewer. You’ll find file paths, text passages and vectors.

    %APPDATA%\app.winfynd.desktop\index.sqlite3

  • Read the log

    Paste the folder into File Explorer’s address bar and open winfynd.log in Notepad. It is plain text.

    %LOCALAPPDATA%\app.winfynd.desktop\logs
